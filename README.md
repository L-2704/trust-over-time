# Trust Over Time

A temporal benchmark of calibration, fairness, and explanation
faithfulness in credit risk models.

## Status
Work in progress.

## Research questions
1. Reliability: how much do predictive performance and probability
   calibration deteriorate as the test period moves further from
   the training period?
2. Fairness: do fairness gaps widen under temporal drift, and do
   calibration fixes help or worsen them?
3. Explanation faithfulness: do feature explanations stay faithful
   to the model's actual behavior as the data changes?

## Data
Lending Club Loan Data (2007-2015), from Kaggle.
The raw data is not included in this repo.

## Models
Logistic regression, Random Forest, LightGBM.
